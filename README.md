# Joz Gallery for Home: design preview

Static preview of the home page design for **Joz Gallery for Home (جوز كاليري)**.
Arabic (RTL) by default, with an English toggle in the header.

Live: https://theitdude87.github.io/joz-gallery-preview/

Product and room photos are demo images from Unsplash and will be replaced with the store's own photos.
This repository holds the generated preview only. It is built with `php tools/build-preview.php --site=...` from the main project.
